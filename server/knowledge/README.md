# Basis pengetahuan Asisten Astro

Disalin dari repository pengguna sendiri, [ihsanmp/Crypto-Analis](https://github.com/ihsanmp/Crypto-Analis)
(commit `61ff5b5`, 21 Okt 2026), tanpa diubah:

- `*.md`: hasil riset yang sudah diuji di repo itu (astro-trading pada BTC, fase bulan, penggerak
  emas dan minyak, jam likuiditas, pola dan regresi log BTC, Minor Swing Astronacci, narasi dan
  rotasi sektor, gaya Kalimasada).
- `peran/*.md`: aturan berpikir analis (kalibrasi keyakinan, proyeksi terukur, risiko).

Dipilih per pertanyaan oleh `src/astrochat/prompt.ts` dan dikirim ke Claude bersama data yang
dikumpulkan kode aplikasi ini. Beberapa berkas menyebut skrip atau workflow repo asalnya
(`cloud/*.py`): itu catatan asal angkanya, bukan sesuatu yang dijalankan di sini.
